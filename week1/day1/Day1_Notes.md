Salesforce Day 1

1. What problem does Salesforce solve?

Salesforce solves the problem of managing scattered customer data and business processes across different systems.
It brings all customer information, sales activities, and communication into one centralized cloud platform, helping companies improve efficiency, sales tracking, and customer relationships.

2. What is CRM?

CRM stands for Customer Relationship Management.
It is a system used by companies to manage customer data, track interactions, and improve relationships with customers to increase sales and customer satisfaction.

3. What is an Object in Salesforce? Give one example.

An Object in Salesforce is like a database table used to store specific types of data.

Example:

Account → Stores company details
Contact → Stores customer details
Lead → Stores potential customer information

So, an Object is a structure where records are stored.

4. Difference between Salesforce Admin and Developer

Salesforce Admin:

Configures and manages Salesforce system
Manages users, data, reports, and dashboards
Works mainly using settings (no coding required)

Salesforce Developer:

Writes code using Apex and Lightning Web Components (LWC)
Builds custom applications and features
Extends Salesforce functionality beyond standard features


5. Real-world application using Salesforce

One real-world application that can be built using Salesforce is a College Management System.

It can include:

Student management
Attendance tracking
Fee management
Exam records
