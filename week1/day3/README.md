
1. What is Salesforce Platform?
The Salesforce Platform is essentially a cloud-based foundation that gives businesses the tools to build apps without starting from scratch. Instead of managing servers or writing security protocols, it provides a "pre-built" environment so we can focus on the actual business logic.

2. Explain: App, Object, and Tab
App: This is a collection of features and tools grouped together for a specific job, like a "Sales" or "Service" app.

Object: These are the database tables where the information is actually stored—think of them like spreadsheets for things like "Leads" or "Students".

Tab: A Tab is the visual link at the top of the page that acts as a shortcut to open a specific object.

3. Difference: Configuration vs. Coding
Configuration: This is "clicking" rather than "typing". It uses built-in tools like Flow Builder for standard automation.

Coding: This involves writing Apex or JavaScript code for highly specific or complex requirements that standard tools can't handle.
